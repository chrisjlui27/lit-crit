# Lit Crit

Coaching workspace for a high-school **UIL Literary Criticism** team,
2026-27 season. Planning material only: season plan, study tracks,
practice sets, essay work, official UIL resources, and progress trackers.

This year: Hawthorne's short stories, Anne Bradstreet's poems, and Neil
Simon's *Lost in Yonkers*. Practice runs as four 10-minute q-time sessions
a week. District Lit Crit is April 2, 2027.

Start with:

1. `season/season-plan.md` for the weekly rotation and reading schedule.
2. `season/calendar.md` for dates.
3. `reading-list/2026-2027.md` for the list, editions, and prize windows.
4. `terms/most-tested-terms.md` for what Part 1 actually asks.
5. `contest/format.md` to brief new students on the exam.

See `CLAUDE.md` for the layout and conventions, including the rule against
committing student data.
