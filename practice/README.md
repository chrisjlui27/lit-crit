# Practice

- `template.md`: the layout for a homemade practice set with a separate key.
- `tests/`: one file per practice set, named `YYYY-MM-DD-<source>.md`, e.g.
  `2026-12-05-part1-terms-batch-c.md` or `2027-01-09-full-2024-district.md`.
  Do not commit copyrighted UIL tests themselves; log that they were used.
- `error-logs/`: one file per timed test per student code. Every missed item
  gets a row.
- `scores.csv`: every timed test, per part, per student code.

## Sources of full-length tests

- Prior-year UIL tests (UIL store, sets from Invitational A/B, District,
  Regional, State).
- Hexco practice packets.
- Homemade sets from `/practice-test` for the reading list and terms
  batches; these are for drilling, not for calibrating scores.

## Rotation

Use older tests first and keep the two most recent full tests unseen for
the two weeks before District.
